# Fingerprint Fields

## Core Fields

- `narrative_mode`: POV, tense, distance, reliability.
- `sentence_rhythm`: short/medium/long mix, fragment use, paragraph length.
- `dialogue_system`: ratio, attribution, action beats, subtext level.
- `description_protocol`: sensory priority, object detail, environment refresh.
- `emotion_protocol`: how emotion appears on page.
- `pacing_protocol`: scene/summary balance, hook frequency, transition style.
- `lexicon`: preferred word classes, imagery sources, register.
- `forbidden_patterns`: cliches, AI-like phrases, tonal mismatches.
- `reusable_prompt`: compact style instruction for later draft tasks.
