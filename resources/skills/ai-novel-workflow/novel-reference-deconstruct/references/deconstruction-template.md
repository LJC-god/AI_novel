# Deconstruction Template

## Required Sections

- `reference_identity`: title/source/format if known.
- `reader_promise`: the emotional or curiosity promise.
- `opening_hook`: first pressure, first question, first payoff signal.
- `structure_map`: 5-12 beats depending on length.
- `emotion_curve`: expectation, suppression, escalation, release.
- `craft_patterns`: reusable patterns, each written as an instruction.
- `nontransferable_parts`: details that should not be copied.
- `application_notes`: how to apply the pattern to the current project.

## Beat Labels

Use these labels when useful:

- `hook`
- `status_quo`
- `pressure`
- `choice`
- `reversal`
- `payoff`
- `new_question`
- `cliffhanger`
