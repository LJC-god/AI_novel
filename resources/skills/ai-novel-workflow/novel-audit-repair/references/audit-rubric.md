# Audit Rubric

## Categories

- Continuity: timeline, facts, names, relationship state, world rules.
- Character: desire, fear, voice, agency, decision logic.
- Plot: causality, stakes, conflict, payoff, unresolved hook.
- Pacing: scene length, repetition, exposition, payoff density.
- Style: POV consistency, sentence rhythm, dialogue format, description protocol.
- AI trace: generic phrasing, excessive explanation, summary tone, uniform rhythm.

## Repair Output

- Name the problem.
- Explain why it hurts the chapter.
- Give the smallest viable fix.
- Provide rewritten text only when requested or when the task is `chapter-repair`.
