# 立项定位：杀敌爆经验，但经验先发给敌人

## 核心判断

- 推荐优先级：第 3 本
- 题材：东方玄幻 / 极道升级 / 规则智斗
- 目标篇幅：150-220万字
- 目标平台：番茄小说男频
- 30字卖点：杀敌经验先发给敌人，主角靠布局让敌人突破后反噬。
- 读者承诺：每一场越级战都是三层布局和清楚结算。敌人越升级，死得越精准。

## 主角身份与开篇处境

秦昼是青岩城秦家旁支弃子，被推上家族试炼当垫脚石。开篇压力不是抽象的“他很惨”，而是具体事件：家族试炼开始前，嫡子秦骁要用他立威，还逼他签生死约。

## 一句话钩子

杀敌爆经验系统会先把经验临时发给敌人，让敌人临战突破；秦昼必须提前布置，让敌人突破后反噬、自爆、欠债。

## 150-250字简介

秦家旁支秦昼被推入家族试炼，原以为觉醒杀敌爆经验系统就能翻身，没想到经验会先发给敌人。敌人越打越强，旁人都以为他死定了。秦昼却发现，临时突破会放大旧伤、丹毒、誓约和地形缺陷。于是他从一个被踩的弃子，变成专门给敌人“送升级”的布局者。

## 可持续爽点循环

1. 敌人用资源、规则或身份压人。
2. 秦昼不直接硬刚，先让敌人把动作做满。
3. 经验回收印记录或触发规则。
4. 主角用规则漏洞结算敌人的违规、浪费或反噬。
5. 收益落到实处：资格、资源、名声、线索、盟友。
6. 新敌人发现主角异常，下一章压力升级。

## 风险与修正

- 风险：规则爽文容易解释过多。
- 修正：每章只解释一个新规则，其余用行动证明。
- 风险：老六笑点变成段子。
- 修正：笑点必须改变局势、诱导敌人犯错或推进关系。
- 风险：开篇设定堆积。
- 修正：前3章只围绕一个公开事件写，不扩散大世界。
