# 番茄第一批 9 个选题池

生成时间：2026-06-10

依据：优先限定在都市、玄幻、仙侠三条线。番茄 2026 长篇征文公开信息中，都市高武、传统玄幻、玄幻脑洞、东方仙侠等方向被列为适宜改编开发分类；这里保留“老六搞笑、反套路、强情绪、强钩子”，同时避免只服务个人爱好。

## 使用方式

1. 先选 1 个选题池，不要混多个。
2. 进入总控 Agent，让它基于该选题池生成：书名、简介、读者承诺、总纲、卷纲。
3. 确认总纲后，再生成世界观、角色、关系、伏笔账本。
4. 第一卷章纲确认后，按单章顺序写正文，不并行多章。

## 推荐模型组

- 总控 / 立项判断：GPT-5.5
- 灵感扩展 / 反套路笑点：GLM 5.1
- 大纲 / 因果链 / 章纲：DeepSeek V4
- 设定资产 / 人物关系 / 拆书吸收：Claude Sonnet 4.6
- 正文初稿：DeepSeek V4
- 审稿修复 / 去 AI 味 / 番茄节奏：Claude Sonnet 4.6 + GLM 5.1

## 01 都市高武：我靠扣寿命把武学氪成负数

- 类型：都市高武 / 老六极道流
- 篇幅：长篇，120-180 万字
- 平台：番茄男频
- 核心钩子：主角被诬陷成废人，觉醒“寿命抵扣系统”，别人氪命变强，他发现系统可以把敌人的违规代价算进自己的账户，越被针对越赚钱。
- 前三章开法：开局模拟考主角筋脉崩坏，被班主任要求退考；反派当众递来赔偿协议；主角签字后把协议条款反向触发，第一拳打出“欠费武学”。
- 可持续爽点：寿命账单、武考打脸、校队资源争夺、武馆黑幕、城市秘境、敌方组织违规套利。
- 老六笑点：主角每次开打前先问“开发票吗”，把战斗打成财务审计。
- 风险：氪命容易压抑。修正：每次代价都转成可见收益和敌人反噬，不写苦大仇深。
- 推荐 skill：`novel-market-scan`、`fanqie-premise-positioning`、`novel-pleasure-points`、`novel-chapter-draft`。
- 推荐模型：GLM 5.1 出脑洞，DeepSeek V4 做大纲和正文，Claude Sonnet 4.6 审核战力体系。

## 02 都市脑洞：反诈主播，专骗骗子修仙

- 类型：都市脑洞 / 直播 / 轻喜剧
- 篇幅：中长篇，80-120 万字
- 平台：番茄男频
- 核心钩子：主角是底层反诈主播，意外绑定“谎言灵气系统”：只要骗子相信他的假身份，就会掉落技能和线索。
- 前三章开法：开局直播连线杀猪盘，对方冒充仙门客服；主角顺着演成“监察仙君”，反手骗出整个诈骗窝点的组织图。
- 可持续爽点：直播围观、骗子反被骗、都市奇人、地下灰产、超凡身份误会升级。
- 老六笑点：主角一本正经给骗子讲“修仙反诈法”，弹幕以为剧本，警方以为卧底。
- 风险：现实诈骗题材可能沉重。修正：只取骗局结构，不写真实受害细节，用喜剧反杀承接。
- 推荐 skill：`novel-premise-design`、`novel-emotion-pacing`、`fanqie-golden-three`、`novel-audit-repair`。
- 推荐模型：GPT-5.5 控制边界，GLM 5.1 做直播梗，DeepSeek V4 搭主线。

## 03 都市重生：我重生后只想摆摊，前世仇人全来加盟

- 类型：都市重生 / 小生意逆袭 / 群像喜剧
- 篇幅：长篇，100-150 万字
- 平台：番茄男频
- 核心钩子：主角前世创业被资本围剿，重生后只想摆摊还债，却因为信息差和老六操作，把前世仇人一个个变成加盟商。
- 前三章开法：开局回到破产前夜，主角没有豪言壮语，先抢占夜市最差摊位；反派来羞辱，他现场做出“穷鬼套餐”卖爆。
- 可持续爽点：小生意升级、商业打脸、供应链反杀、敌人变工具人、城市烟火气。
- 老六笑点：主角每次报复都包装成“合作共赢”，反派亏着钱还要送锦旗。
- 风险：都市商业容易流水账。修正：每卷锁一个敌人和一个行业矛盾，避免纯经营日志。
- 推荐 skill：`novel-commercialization`、`novel-outline-engine`、`novel-character-arc`、`novel-polish-humanize`。
- 推荐模型：Claude Sonnet 4.6 做人物网，DeepSeek V4 做商业因果，GLM 5.1 做段子。

## 04 玄幻脑洞：全宗门都是反派，只有我按门规作恶

- 类型：玄幻脑洞 / 宗门 / 反套路
- 篇幅：长篇，120-200 万字
- 平台：番茄男频
- 核心钩子：主角穿进魔宗，发现全宗门都在偷偷洗白，只有他认真执行“作恶门规”，结果每次都误打误撞救人、涨功德、升职位。
- 前三章开法：开局主角被罚去抢村，结果发现村民是假扮的正道钓鱼队；他按门规先写抢劫告知书，反把正道流程漏洞曝光。
- 可持续爽点：魔宗制度喜剧、正邪身份错位、功德误会、宗门升职、正道反派化。
- 老六笑点：主角越想当坏人，越被天下人误认为“魔宗良心”。
- 风险：梗太喜剧可能撑不长。修正：中期揭示正邪秩序被上层操控，主角从误会流转为制度破局。
- 推荐 skill：`novel-genres`、`novel-setting-system`、`novel-pleasure-points`、`fanqie-chapter-rhythm`。
- 推荐模型：GLM 5.1 负责反套路，Claude Sonnet 4.6 负责正邪制度，DeepSeek V4 写主线。

## 05 玄幻极道：杀敌爆经验，但经验先发给敌人

- 类型：东方玄幻 / 极道升级 / 智斗
- 篇幅：长篇，150-220 万字
- 平台：番茄男频
- 核心钩子：主角获得杀敌爆经验系统，却发现经验会先临时发给敌人，让敌人临战突破；主角只能用布局让敌人突破后自爆、反噬、欠债。
- 前三章开法：家族试炼中反派临阵突破，全场以为主角死定；主角早在丹药、地形、誓约里埋了三层扣子，反派突破越快死得越准。
- 可持续爽点：越级反杀、敌人被迫变强、经验回收、家族夺权、秘境局中局。
- 老六笑点：主角口头禅“你先升级，我不急”，敌人听完更慌。
- 风险：规则复杂。修正：每次只展示一个规则变化，战斗结算必须清楚。
- 推荐 skill：`novel-outline-engine`、`novel-setting-system`、`novel-audit-repair`、`novel-chapter-plan`。
- 推荐模型：DeepSeek V4 设计规则战，Claude Sonnet 4.6 查漏洞，GPT-5.5 控总线。

## 06 玄幻经营：宗门破产后，我把祖师爷租出去了

- 类型：玄幻宗门经营 / 祖师爷 / 爽文喜剧
- 篇幅：中长篇，90-140 万字
- 平台：番茄男频
- 核心钩子：主角继承濒临破产的小宗门，祖师爷残魂只会吹牛。他发现祖师爷的名号还能担保、出场、背锅，于是把宗门债务变成影响力生意。
- 前三章开法：债主上门拆山门，主角不求饶，直接推出“祖师爷显灵体验券”；残魂被迫营业，一句话吓跑债主。
- 可持续爽点：宗门翻盘、弟子招募、祖师爷社死、门派联盟、资源盘活。
- 老六笑点：祖师爷每天骂主角欺师灭祖，第二天继续接商演。
- 风险：经营线慢热。修正：每章必须有债务压力或外部挑战，不写纯建设。
- 推荐 skill：`novel-worldbuilding`、`novel-character-arc`、`novel-emotion-pacing`、`novel-polish-humanize`。
- 推荐模型：Claude Sonnet 4.6 做群像，GLM 5.1 做祖师爷吐槽，DeepSeek V4 做经营升级。

## 07 东方仙侠：炼丹炉成精后，天天举报我偷工减料

- 类型：东方仙侠 / 炼丹 / 老六师徒
- 篇幅：长篇，120-180 万字
- 平台：番茄男频
- 核心钩子：主角是底层丹徒，靠“省料炼丹”混日子，意外唤醒会说话的炼丹炉。丹炉绑定天道质检，天天举报他，他反而利用质检规则炼出低成本神丹。
- 前三章开法：开局宗门丹考，主角被安排最差药材；炼丹炉当众举报他少放三味药，结果炸炉后喷出一颗“穷鬼版破境丹”。
- 可持续爽点：丹方改造、质检规则、宗门内卷、丹道打脸、天道漏洞、药材产业链。
- 老六笑点：丹炉像监工，主角像会计，两人一边互坑一边发财。
- 风险：炼丹细节可能重复。修正：每卷换一个丹道场景：考试、黑市、宗门战、秘境药园、仙城垄断。
- 推荐 skill：`fanqie-premise-positioning`、`novel-setting-system`、`novel-chapter-draft`、`fanqie-submission-audit`。
- 推荐模型：GLM 5.1 扩炼丹笑点，DeepSeek V4 写正文，Claude Sonnet 4.6 审丹道规则。

## 08 东方仙侠：我在仙门做账，算哭了三界大能

- 类型：东方仙侠 / 账房 / 幕后流
- 篇幅：长篇，100-160 万字
- 平台：番茄男频
- 核心钩子：主角没有灵根，只是仙门账房，却能看见“因果账”。别人斗法，他查账；别人渡劫，他算税；大能越强，账越脏。
- 前三章开法：开局主角被裁员，临走前发现掌门渡劫失败不是天命，而是三百年前一笔香火账没平。
- 可持续爽点：账本破案、因果追债、无灵根逆袭、仙门黑幕、三界审计。
- 老六笑点：主角对仙尊说“您这个天劫可以分期”，仙尊当场破防。
- 风险：主角战斗力不足。修正：把“算账”设计成因果法术，逐步获得可执行的制裁能力。
- 推荐 skill：`novel-premise-design`、`novel-outline-engine`、`novel-reference-deconstruct`、`novel-audit-repair`。
- 推荐模型：GPT-5.5 控创意边界，DeepSeek V4 做因果链，Claude Sonnet 4.6 做伏笔账。

## 09 东方仙侠：飞升考试三次不过，我改去当考官

- 类型：东方仙侠 / 飞升考试 / 制度流喜剧
- 篇幅：中长篇，90-130 万字
- 平台：番茄男频
- 核心钩子：主角飞升考试三次不过，发现不是自己菜，而是考试体系被仙界门阀垄断。他转头考进巡考司，从改卷、查舞弊、抓替考开始掀翻飞升秩序。
- 前三章开法：开局第三次飞升失败，主角被全城嘲笑；他没有当场逆天，而是把判卷仙吏的错别字贴满城门。
- 可持续爽点：考试打脸、制度漏洞、寒门修士共鸣、仙界门阀、巡考办案。
- 老六笑点：主角的法宝是红笔，批语比飞剑还伤人。
- 风险：考试梗可能校园化。修正：把考试升级为飞升资源分配制度，后期接仙界权力斗争。
- 推荐 skill：`novel-market-scan`、`novel-character-arc`、`novel-emotion-pacing`、`fanqie-golden-three`。
- 推荐模型：GLM 5.1 做笑点和题名，DeepSeek V4 做制度线，Claude Sonnet 4.6 做人物阵营。
