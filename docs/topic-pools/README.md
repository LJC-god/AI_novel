# Topic Pools

This folder stores market-facing novel topic pools that can be reused by the AI novel workflow.

- `fanqie-first-9-topic-pools.md`: readable planning document for the first 9 topic pools.
- `fanqie-first-9-topic-pools.inspiration.json`: CharacterArc 2.0 inspiration import package.

Use the JSON file from Settings -> Import JSON, then choose the inspiration module and append/copy mode.
